# 智能体笔记：Web 外壳的手机布局

Status: implemented

[English](2026-11-06-phone-layout-shell.md) | 中文

## 问题

外壳的窄屏档位止步于自动折叠的 56px 轨道。在 390px 的手机上，这条轨道占去 14% 的宽度，却始终不会变成会话列表，而详情栏更完全无法打开（`computeColumns` 在约 1000px 以下把它解为 0）。头部还带着三块手机无法处理的装饰：会话的智能体预设标签、视图页签条、会话日志下载胶囊。输入区控件是按指针尺寸设计的（28px 小圆、34px 发送圆），外壳又把自身固定在布局视口的 `height: 100%`，而移动端的地址栏与键盘并不会收缩它。

## 决定

**手机布局是 `ui-layout` 中的第三个档位，而不是另一套外壳。** `AppFrame` 用它自己 `ResizeObserver` 已经量到的宽度判定（`MOBILE_MAX = 767`），保留全部三条网格轨道（`minmax(0, 1fr) 0px 0px`），使脱流的侧栏和空的详情栏不会形成隐式行，并把侧栏列移出流成为滑动的抽屉。`computeMobileColumns` 拥有该解算。store 新增 `mobile` 与 `drawerOpen`；在那里 `toggleSidebar` 翻转抽屉而不再翻转宽度偏好，`openDetails` 被拒绝，两个方向的断点跨越都会丢弃抽屉状态。

**手机装饰由框架自身拥有。** 菜单控件与遮罩由 `AppFrame` 渲染，而不是由另一个插件渲染：侧栏槽只能由声明它的框架渲染，因此任何插件都无法把会话列表搬进抽屉。框架内的层叠顺序是 shell overlay (20) < 遮罩 (21) < 菜单 (22) < 抽屉 (23)，遮罩仅在抽屉打开时存在（一个覆盖会话的可穿透层会吞掉每一次触摸），而抽屉始终承载**宽版**侧栏——轨道是桌面端的便捷物，手机没有宽度可供它消耗。

**装饰几何以 owner props 跨包传递，绝不用选择器。** 框架把 `headerInset` 与 `mobile` 传入 `conversation` 槽；会话把该内缩量转成自己根部的 `--dsh-header-inset` 自定义属性，使头部让开菜单控件，并在头部与主体两处都把视图环收敛到 Chat，于是页签条消失，而从更宽布局带过来的选择会解析为 Chat，而不是渲染一张该列装不下的事件账本。

**两处界面在自己的样式表里隐藏自己。** `ui-agent-preset` 隐藏头部标签，`session-log-export` 隐藏下载胶囊，规则都在 `@media (max-width: 767px)` 之下。把二者从组合中移除被否决：组合无法按设备变化，因为同一个 URL 同时服务手机与桌面。`ui-conversation` 在同一断点上把输入区的小圆、下拉与发送圆放大到 36px，并用 `env(safe-area-inset-bottom)` 为输入座留出底部安全区；`ui-layout` 的语言命名空间提供菜单控件的名称；外壳基础样式表改用 `100dvh`，`apps/web` 声明 `viewport-fit=cover`、`interactive-widget=resizes-content`、`theme-color` 与 `standalone` 清单。

## 考虑过的替代方案

**由一个 fork 自有的手机外壳插件注册到 `shell.overlay`。** 因能力而非口味被否决：插件只能渲染自己声明的槽，因此它可以添加装饰，却永远无法在抽屉里承载 `sidebar` 槽。它只会围绕一个无法移动的会话列表产出重复装饰。

**在框架样式表里用跨包选择器隐藏页签条与其他装饰。** 被否决，因为原型里的 `div:has(> [data-shell-overlay])` 一类选择器会伸进其他包的 DOM 与其哈希类名。owner props 通过受认可的通道陈述同一件事，而隐藏规则留在拥有这些元素的包里。

**在手机配置档中移除 `ui-trajectory` 与导出命令。** 被否决，因为配置档无法按设备变化；手机与桌面共用一个 URL。视图仍被注册，并在更宽的布局上仍可到达。

**只用 CSS 强制视图。** 被否决，因为只隐藏页签条会让一条持久化的 Trajectory 选择在手机上渲染出来且无路可退。在 JS 里收敛视图环，使页签条与主体拥有同一个事实来源。

## 后果

手机把整幅宽度给了会话，用抽屉承载会话与工作区，并且不再有无法使用的头部装饰。选择会话会关闭抽屉，在列发生重叠之处也没有任何列边可被拖动。断点以上的桌面布局不变，回放的 Web 快照与新增 e2e 场景的 1280px 一段都钉住了这一点。

代价是明确的。在后续规范为它们给出整屏表面之前，手机没有详情栏，也没有 Trajectory；`/export` 作为命令仍然存在，只是按钮被隐藏；抽屉的关闭手势是遮罩或侧栏自带的切换按钮，因为框架无法观察落在另一个包槽内的会话点击。确定形态的原型是一个动态 Cordis 客户端插件，其 CSS 跨包选择；它不属于已交付代码。
